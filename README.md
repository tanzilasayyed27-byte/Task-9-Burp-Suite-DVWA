# Task 9 – Advanced SQL Injection Testing Using Burp Suite

## 📌 Overview

This project demonstrates web application security testing using **Burp Suite** against the intentionally vulnerable **Damn Vulnerable Web Application (DVWA)** in a controlled local laboratory environment.

The task focuses on intercepting, inspecting, and analyzing HTTP requests and responses.

## 🎯 Objectives

- Understand the basic workflow of Burp Suite.
- Intercept HTTP requests generated by DVWA.
- Analyze request parameters and HTTP headers.
- Use Burp Repeater for controlled request analysis.
- Inspect HTTP responses.
- Review requests using HTTP History.
- Understand the importance of secure input validation.

## 🛠️ Tools Used

- Kali Linux
- Burp Suite Community Edition
- DVWA
- Docker
- Web Browser
